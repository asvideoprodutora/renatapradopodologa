SITE DE PODOLOGIA — GITHUB PAGES

1. Abra index.html no navegador para testar.
2. Crie/adicione as fotos na pasta fotos com estes nomes:
   capa.jpg, profissional.jpg, 1.jpg, 2.jpg, 3.jpg, 4.jpg, 5.jpg, 6.jpg
3. Abra index.html em um editor e procure por "const CONFIG".
   Troque o WhatsApp (55 + DDD + número), nome, endereço, horário e Instagram.
4. Edite textos e serviços para refletir apenas os serviços reais oferecidos.
5. No GitHub, crie um repositório público e envie index.html e a pasta fotos.
6. Em Settings > Pages, escolha Deploy from a branch, main e /(root). Salve.
7. Aguarde a publicação e acesse o endereço exibido pelo GitHub.

ATENÇÃO: o site é estático e não precisa de Java ou PHP.
Não publique fotos de clientes sem autorização.
